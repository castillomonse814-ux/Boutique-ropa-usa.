# 🛍️ Boutique Ropa USA - Tienda Online

Bienvenido al repositorio de la tienda online dedicada a la venta de **ropa americana nueva**. 

---

## 📌 Descripción del Proyecto
Este sistema permite gestionar el catálogo de prendas, ver disponibilidad de ropa nueva importada y facilitar la experiencia de compra a los clientes.

---

## 🚀 Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP / Node.js
* **Base de Datos:** MySQL

---

## 📦 Características Principales
* 👕 **Catálogo de prendas:** Visualización de ropa americana nueva por categorías (dama, caballero, niños).
* 🔎 **Filtros de búsqueda:** Por talla, tipo de prenda y precio.
* 🛒 **Carrito de compras / Pedidos:** Gestión básica de solicitudes.
* 📱 **Diseño responsivo:** Adaptado a dispositivos móviles y computadoras.
